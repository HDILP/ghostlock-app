# 5.10 Port — OPPO Reno11 Pro (PJJ110)

> GhostLock (CVE-2026-43499) 5.10 移植实验。
> Status: **所有已知利用路径在5.10上不可行** (2026-08-19)。

## Target

| Field          | Value                                        |
|----------------|----------------------------------------------|
| Device         | OPPO Reno11 Pro (PJJ110)                     |
| SoC            | Snapdragon 8+ Gen 1 (SM8475)                 |
| System         | ColorOS 15, PJJ11015.0.0.861(CN01B40P02)     |
| Kernel         | `5.10.226-android12-9-o-gbf90590695a1`       |
| Hardening      | PAC + SCS + Clang CFI + KASLR + KPTI         |
| Vuln status    | **未修复** — remove_waiter() 使用 current 而非 waiter->task (fix = 5.10.261, upstream 3bfdc63936dd) |

## 漏洞分析

### upstream fix (3bfdc63936dd)

| 旧代码 (有 bug)                   | 新代码 (修复后)                  | 影响                          |
|----------------------------------|--------------------------------|-------------------------------|
| `raw_spin_lock(&current->pi_lock)` | `raw_spin_lock(&waiter_task->pi_lock)` | 锁正确的 task |
| `current->pi_blocked_on = NULL` | `waiter_task->pi_blocked_on = NULL` | 清除正确的 PI 状态 |
| `..., current` in adjust_prio_chain | `..., waiter_task` | chain walk 用正确的 task |

### 已证明不可行的路径

#### 1. pi_waiters rb_erase (DEAD)
- Guard at 0x81ec0d0 要求 `w26=1`
- `w26=1` 需要 `lock == waiter_struct_pointer`，正常控制流下永远不成立
- Phase 4 的 crash 是 remove_waiter → tree_entry erase 的偶然，不是 pi_waiters 路径

#### 2. NFDS=320 pselect 覆写 (DEAD)
- vendor 添加了 `BUG_ON(root->lock != lock)` 检查（3 处 brk #0x800）
- waiter+0x38 (lock 字段) 被覆写后立即触发，无法绕过
- 6.x 内核没有此 vendor 检查，所以公开 exploit 只在 6.x 上工作

#### 3. dangling pi_blocked_on UAF (DEAD)
- 理论：remove_waiter 清除 current 而非 waiter_task → waiter_task->pi_blocked_on 悬垂
- **实际情况**：`try_to_take_rt_mutex` (0x1ea4b8) 在 waiter_task 成功获取锁时清除其 `pi_blocked_on`
- Phase 6 实验验证：15/15 稳定无 crash
- waiter_task 返回 userspace 时 `pi_blocked_on = NULL`，不是悬垂指针

#### 4. KGSL GPU exploit (DEAD)
- CVE-2025-21479 exploit (cheese/FreeXR) 在设备上运行失败
- "can't get GPU r/w" — 漏洞已修补或 GPU pagetable 布局不兼容

## Dead-end paths (勿重复尝试)

1. **pi_waiters rb_erase** — guard w26=0 恒假，结构性不可达
2. **NFDS=320 waiter 覆写** — vendor BUG_ON 阻止
3. **dangling pi_blocked_on** — try_to_take_rt_mutex 清除
4. **KGSL GPU r/w** — 漏洞已修补
5. **consumer tree_entry write** — rb_link_node 重置 rb_right/rb_left
6. **requeue waiter tree erase** — list guard 守卫

## 坑

- OPPO pstore 加密, crash log 在 DDR dump (10GB raw, 搜不到)
- adb 端口每次 panic 后变
- push 失败重试 6×10s
- stdout 全缓冲: panic 后电脑端收不到 post-select 输出, 用 punch_seq 落盘
- /data/local/tmp 文件 panic 后回滚, 日志写 /sdcard/Download/ 更稳
